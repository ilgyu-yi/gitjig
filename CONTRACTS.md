# Contracts

## C0. Status and interpretation

These are target product contracts, not claims of implemented support. Preconditions and outcomes below define observable acceptance. Each implementation must declare its supported environment and enforcement coverage. Design owns structure; this document owns behavioral conditions.

The normative subjects are gitjig's implementation and its managed procedure. For an adopting project's task, the actual owner requirements and applicable project rules define the requested feature behavior. Supplying these criteria does not add unrequested gitjig capabilities, installation behavior or whole-product acceptance features to that project. Mandatory agent conduct, independent judgments, verification, pending-finding accounting, execution restrictions and action eligibility still apply to the managed work. In particular, execution/tool/cleanup restrictions also apply to ordinary adopter tasks; they are not installer-only obligations.
